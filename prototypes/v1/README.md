# 衡鉴财务审计工作台前端原型

这是依据项目 PRD 制作的纯 HTML 交互原型，不包含后端、数据库或真实 API 调用。

## 打开方式

直接双击 `index.html`，使用 Edge 或 Chrome 打开即可。不需要安装 Node.js、Python 或其他依赖。

## 已覆盖的交互

- 六个一级区域：项目、资料、分析、风险、输出、设置。
- 资料搜索、状态筛选、拖放与文件选择模拟。
- 多年指标图表、指标切换与增量分析运行状态。
- 风险搜索、筛选、详情抽屉、证据查看和状态更新。
- 输出模板选择、格式选择和生成流程模拟。
- DeepSeek、GLM、Kimi、千问及自定义服务商配置。
- 任务路由、资源上限、严格离线模式和主题切换。
- 桌面端与小屏响应式布局。

## 原型边界

- 文件导入只读取文件名并模拟加入队列，不会上传或解析内容。
- 模型连接测试、OCR、风险分析和报告生成均为前端状态模拟。
- CPU、内存、费用和项目数据均为演示数据。
- 正式开发时可保留当前信息架构，将交互事件接入桌面端后端接口。

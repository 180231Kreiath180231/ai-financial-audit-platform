# V3 到 V3.2 设计审计

## 保留

- 项目、资料、分析、风险、输出、设置六个主功能
- 线索队列、证据画布、复核处置三段工作流
- DeepSeek、GLM、Kimi、Qwen 模型切换
- 在线安全模式、严格离线模式和轻薄本资源保护
- 证据编号、原文件位置和审计日志语义

## 优化

- V3 的卡片容器过多，V3.2 将核心分析区改为连续画布和分区线
- V3 的英文小标题重复出现，V3.2 去除非必要 eyebrow
- V3 的右侧面板一次展示全部信息，V3.2 按复核步骤分层
- V3 的移动端只保留证据画布，V3.2 允许在三个工作区之间切换
- V3 的强调绿较亮，V3.2 使用更克制的绿色并提高辅助文字可读性
- V3 缺少快速跳转，V3.2 增加快捷定位和键盘入口

## 动效原则

仅使用 80-180ms 的状态反馈和布局切换。没有自动播放、滚动劫持、循环动画或装饰性入场效果。所有动效支持 `prefers-reduced-motion`。

# 衡鉴审计工作台 V3.2

V3.2 是基于 V3 的保留式优化版本。它保留六个主功能、证据优先的审计流程、模型切换和本地资源保护，同时降低视觉噪声并改善复核效率。

## 打开方式

直接双击 `index.html`。页面是单文件 HTML，不依赖 npm、CDN、后端服务或本地模型。

## 相比 V3 的主要改进

- 减少重复圆角卡片，使用分区线和留白建立层级
- 降低绿色强调色的饱和度，保留深色金融工作台语言
- 右侧复核区拆分为判断依据、AI 解释、人工处置三个标签
- 新增桌面专注查看，可临时收起右侧处置区
- 新增 `Ctrl K` 快速定位
- 移动端增加线索、证据、处置三段切换，不再隐藏关键工作区
- AI 助手可在已选证据和项目全部资料之间切换回答范围
- 放大关键辅助文字，保留可见焦点、明暗主题和低动效

## 设计参数

- Design variance: 4
- Motion intensity: 2
- Visual density: 8
- 模式：Redesign preserve
- 基础方向：企业分析产品、Swiss 网格、深色金融数据工作台

页面内金额、文件和风险信息均为示例数据。

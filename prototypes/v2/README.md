# 衡鉴审计协同台前端原型 V2

这是根据 AI 财务审计分析平台 PRD 制作的第二套前端方案。它不会覆盖第一版。

## 设计重点

- 左侧项目上下文集中展示风险队列、项目状态与资源保护。
- 中间区域用于资料、规则分析、风险复核和报告输出。
- 右侧常驻审计助手，支持模型切换、证据范围控制和模拟问答。
- 风险详情同时展示本地计算、支持证据和人工状态。
- 严格离线模式会禁用所有需要外部模型的操作。

## 使用方式

直接双击 `index.html`，使用 Edge 或 Chrome 打开。不需要安装任何依赖。

## 原型范围

- 所有项目、风险、费用、CPU 和模型结果均为演示数据。
- 上传操作只读取文件名并模拟加入处理队列。
- 模型问答、OCR、分析和报告生成均为前端流程模拟。
- 正式开发时可将现有交互事件接入本地桌面服务与外部模型 API。

## 关于 Stitch

当前运行环境没有可调用的 Stitch MCP，插件目录中也没有发现 Stitch 连接器。因此本版本为独立设计实现，不宣称由 Stitch 生成。

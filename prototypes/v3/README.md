# 衡鉴审计工作台 V3

这是根据 `ui-ux-pro-max` 设计系统重新构建的独立 HTML 交互原型，不覆盖此前版本。

## 直接使用

双击 `index.html` 即可打开。该原型不依赖 npm、CDN 或后端服务。

## 已实现的原型交互

- 六个主功能：项目、资料、分析、风险、输出、设置
- 审计线索切换、证据定位、处置状态和审计备注
- DeepSeek、GLM、Kimi、Qwen 模型切换示意
- 在线安全模式与严格离线模式切换
- 本地确定性分析运行状态
- 文档导入、报告生成和资源保护设置
- 深色与浅色主题
- 桌面、平板及 375px 手机布局

## 设计约束

- 设计系统：Swiss 风格的高密度金融工作台
- 设计参数：Variance 5、Motion 2、Density 8
- 单一绿色主强调色，风险颜色仅承载语义
- 低动效、可见焦点、键盘可操作、支持 reduced motion
- 本地 HTML 仅用于产品讨论，页面内金额和文件均为示例数据

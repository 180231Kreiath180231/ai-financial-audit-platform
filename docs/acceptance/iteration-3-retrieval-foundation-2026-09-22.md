# 迭代三检索分块与向量就绪基础验收（2026-09-22）

## 范围

本轮为 PRD-RET-002 与 PRD-RET-003 建立安全的本地底座：可追溯分块、向量索引版本契约、索引失效规则、RRF 融合纯函数以及用户可见的检索就绪状态。实现边界见 [ADR-0009](../adr/0009-retrieval-chunks-and-vector-readiness.md)。

## 已实现

- 项目迁移 v8 创建分块、向量索引版本和块向量表，并为既有非空页面确定性回填分块。
- 新导入页面在同一数据库事务内生成分块；块可回溯到页码、原文字符位置、解析版本和 SHA-256。
- 页面分块重建会把已就绪向量索引标记为过期；索引契约强制保存模型、维度、分块版本和后端。
- RRF 纯函数对关键词与向量候选去重、保留来源排名并生成稳定排序。
- 检索状态 API 与前端展示全文块数量、语义索引状态和“未发送数据”，加载、错误及重试状态均来自真实异步结果。

## 浏览器与界面验收

- 使用运行中的本地前后端确认真实状态接口返回“全文 2 段 / 语义检索待配置 / 未发送数据”，没有以 Mock 状态代替后端结果。
- 深色与浅色桌面视口均确认标签、边框和状态文字可辨识。
- 620 px、375 × 812 和 812 × 375 视口确认状态标签可换行、检索输入可操作且页面无水平溢出；375 px 下根元素与正文宽度均等于视口宽度。
- 错误状态使用 `role="alert"` 并提供语义化“重试”按钮；移动端重试按钮最小高度为 44 px。
- 项目全局样式保留清晰 `:focus-visible` 轮廓和 `prefers-reduced-motion` 降级规则。

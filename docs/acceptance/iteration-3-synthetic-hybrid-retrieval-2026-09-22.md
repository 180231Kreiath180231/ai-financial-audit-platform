# 迭代三合成混合检索验收（2026-09-22）

## 范围

本轮在 [ADR-0010](../adr/0010-synthetic-hybrid-retrieval.md) 的边界内完成合成向量、内存余弦召回和 RRF 混合排序闭环，并验证 sqlite-vec 在当前 Windows 环境能够加载与查询。全部业务数据为 synthetic，外部请求为 0。

## 已实现

- 合成项目可从项目检索区域构建版本化测试索引；真实项目被后端硬阻断。
- 固定 64 维特征哈希向量可重复生成，向量 BLOB 与索引维度受数据库外键约束。
- 结构化筛选先约束候选范围，再进行最多 50 个关键词候选与 50 个向量候选的 RRF 融合。
- 混合命中携带稳定 `chunk_id`、页码、块号、精确原文和解析版本，可继续固化为支持证据或反证。
- 新页面或重建分块会让旧索引过期；过期索引不会静默降级为可用结果。
- 前端显示“合成就绪”、当前混合检索开关、未发送数据、构建 pending、失败提示和重试操作。

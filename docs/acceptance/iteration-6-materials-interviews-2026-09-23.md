# 迭代六资料清单与访谈提纲验收记录（2026-09-23）

## 范围

本轮在既有输出草稿中加入资料清单和访谈提纲，使“风险清单 + 资料清单 + 访谈提纲”共用创建、编辑、版本保存和最终固化流程。数据边界以 [ADR-0013](../adr/0013-deterministic-materials-and-interviews.md) 为准。

本轮不改变 Excel v1 工作簿内容，不接入 Word、PDF 或管理层材料，也不调用真实模型。

## 数据与审计控制

- 项目数据库迁移 v11 为输出草稿追加资料清单和访谈提纲标题及 JSON 内容，未删除或覆盖旧列。
- 每项风险生成一条资料项和两条访谈问题，稳定编号分别为 `M-nnn`、`Q-nnn`。
- 用户可编辑标题、资料名称、用途、范围、优先级、访谈对象、问题、目的和顺序。
- 服务端验证项目集合、唯一性和风险关联；新增、删除、重复或改绑会被拒绝。
- 保存与最终固化会把三类成果写入同一个草稿版本；最终固化后服务端拒绝任何修改。
- 生成完全使用快照和本地代码，不引入外部请求、模型结论或新审计规则。

## 界面

- 输出编辑器提供具有语义角色的“风险清单 / 资料清单 / 访谈提纲”三段切换，并显示各分区数量。
- 未保存状态、保存、最终固化和历史版本仍由成果包统一管理。
- 资料与访谈卡片提供明确字段标签和可键盘操作的上移/下移按钮；只读状态与编辑状态可区分。
- 620px 以下改为单列字段与横向紧凑分区导航，无需拖拽或横向滚动才能完成排序。

## 自动化验证

- 后端专项：确定性生成、编辑、排序、版本保存、最终锁定、项目集合篡改与风险改绑拒绝。
- 数据迁移：从既有项目库升级到 v11，旧草稿使用空分区默认值且历史不被改写。
- 前端单测：三类分区可发现、可切换，成果包保存、固化和 Excel 导出流程保持可用。
- `scripts/check.ps1`：前端 ESLint、26 项 Vitest、生产构建及 83 项后端 pytest 全部通过。
- Playwright：9 项适用场景通过，7 项按桌面或移动项目条件有意跳过；桌面输出场景实际检查 1 条资料项、2 条访谈问题、最终固化和 Excel 下载。

## 浏览器验收

- 桌面深色与浅色主题均检查资料清单、访谈提纲、统一保存状态和版本历史，控制台无错误或警告。
- 375×812 与 812×375 视口的根元素、正文和视口宽度一致，无页面级横向溢出。
- 窄屏表单使用不低于 16px 的输入字号和至少 44px 的控件高度；排序操作保留显式按钮，不依赖拖拽。

## 结论与后续

资料清单和访谈提纲已进入真实、可版本化、可固化的本地草稿闭环。下一步按 ADR-0012 接入 Word 模板，并让 Word 从同一已固化草稿读取三类成果内容。

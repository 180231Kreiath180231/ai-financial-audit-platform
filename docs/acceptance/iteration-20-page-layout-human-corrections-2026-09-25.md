# 迭代二十 PDF 版面与人工文本校正验收记录（2026-09-25）

## 范围与结论

本轮完成无需 API Key 的 PDF 版面与人工校正基础闭环，业务边界以 [ADR-0024](../adr/0024-native-pdf-layout-and-human-text-corrections.md) 为准。

- 原生 PDF 新导入页面保存页面尺寸、文本块和归一化区域坐标。
- 保守识别表格候选，并明确标记为未确认线索，不产生审计结论。
- 阅读器提供渐进展开的“版面与人工校正”面板，可按文本块修改当前有效文本并填写原因。
- 来源文本保持不可变，每次人工校正追加版本历史；全文索引和检索分块同步更新，既有向量索引标记待重建。
- 扫描页和旧数据没有可靠坐标时继续只显示页码定位，不伪造区域精度。
- 数据库升级到 v19；既有风险、证据、输出草稿和导出历史均未改写。

PRD-DOC-002 已形成完整的本地生产契约。PRD-DOC-004 当前为部分实现：文本校正及历史已完成，结构化金额、风险类型和表格单元格校正仍等待业务语义确认。

## 未包含事项

1. 不接入真实 OCR、视觉、文本或 Embedding API，也不使用真实客户资料。
2. 不自动确认表格结构，不提取或改写结构化金额、风险类型和审计结论。
3. 不重跑旧文档版面；旧页面只有在重新导入/解析后才会获得新的区域坐标。
4. 正式扫描件识别质量、两家视觉服务商兼容和真实 Embedding 质量仍在 API 接入阶段验收。

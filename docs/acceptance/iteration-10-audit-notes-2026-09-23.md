# 迭代十审计备忘录验收记录（2026-09-23）

## 范围

本轮完成 PRD-NOTE-001 的本地闭环：一个项目可保存多条审计备忘录，记录标题、正文、标签与时间，关联多个风险和文档页，由用户独立控制模型是否可以读取，并在删除前确认。安全语义以 [ADR-0018](../adr/0018-project-audit-notes.md) 为准。

本轮不新增真实模型读取备忘录的任务，也不改变全局严格离线与项目外发授权策略。

## 实现结果

- 项目数据库迁移 v16 新增备忘录和两类关联表，外键删除只清理关联数据。
- 后端提供项目级列表、创建、更新和删除 API；标题、正文和标签在服务端规范化，无效风险或页码会使事务完整回滚。
- 创建、更新、删除均记录审计事件，删除事件不保留正文副本。
- 风险工作区增加“审计备忘录”二级入口；编辑器支持风险多选、文档页精确关联和反向打开。
- 模型读取许可默认关闭，界面明确说明开启不等于外发，既有离线和项目权限仍然优先。
- 删除使用原生确认对话框，支持 Escape、初始取消焦点和忙碌状态保护；移动端保持 44px 操作目标。

## 自动化验证

- 后端专项覆盖创建、更新、删除、关联去重、审计内容、级联清理及无效页码回滚。
- 前端组件测试覆盖完整保存载荷、删除前确认和关联对象跳转。
- 桌面 Playwright 场景覆盖新建、更新、模型可读标识及确认删除。
- 完整本地门禁通过：前端 lint、33 项组件测试、生产构建、后端 Ruff、104 项后端测试，以及 Playwright 10 项通过、8 项按桌面/移动条件跳过。

## 结论与后续

PRD-NOTE-001 的生产路径已完成。下一批可按追踪矩阵进入 PRD-RISK-002 统计分析，或先执行目标 Windows 设备的 P01 至 P07 实机门禁；任何后续模型读取功能都必须复用本 ADR 的显式许可和网关边界。

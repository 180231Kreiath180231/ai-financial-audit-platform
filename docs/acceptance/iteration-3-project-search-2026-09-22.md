# 迭代三项目级全文检索验收（2026-09-22）

## 范围

本轮将既有页级原文升级为项目级本地 FTS5 检索，并把跨文档命中直接接入支持证据、反证和 PDF 页码跳转。关联 PRD-RET-001、PRD-RET-003、PRD-RET-004、F06 与 F07。

## 已实现

- 项目迁移 v6 使用 trigram 重建既有页级全文索引，并为新增、更新和删除维护同步触发器。
- 中文连续词和三字符以上内容走 FTS5；一至两个字符走精确子串回退；文件名在本地补充召回。
- 项目级检索 API 支持文档、页码和结果数边界，响应包含完整证据定位与解析版本字段。
- 命中片段保持为原文精确子串，可直接进入既有服务端证据复核与风险版本链。
- 左侧资料队列提供明确的 loading、empty、error 和命中状态；结果可打开 PDF 准确页码，也可标记为支持证据或反证。
- 所有检索均为本地操作，界面明确显示未调用外部服务。

## 验证

- 后端 Ruff：通过。
- 后端 Pytest：59 项通过。
- 前端 ESLint、Vitest（15 项）与生产构建：通过。
- Playwright：8 项通过，6 项按设备条件跳过；覆盖项目级命中、PDF 跳转和项目检索结果创建风险证据。
- 浏览器检查：桌面深色、940×800 浅色、390×844 竖屏和 844×390 横屏均无页面级横向溢出；可见按钮在移动视口不小于 44×44 CSS px。

## 尚未完成

- 外部 Embedding、向量索引版本和混合排序尚未实现。
- 年度、主体、科目与文档类型过滤已由后续[结构化检索增量](iteration-3-structured-search-2026-09-22.md)补齐；自动元数据抽取仍未实现。
- 当前结果不做字符级 PDF 高亮，只保证文档、页码、文本块和原文引用准确。

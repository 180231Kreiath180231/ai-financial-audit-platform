# 迭代五输出草稿与 Excel 导出验收记录（2026-09-23）

## 范围

本轮在不可变风险快照之上完成“创建草稿 → 人工编辑 → 保存版本 → 最终固化 → Excel 生成与下载”的真实本地闭环。产品决策与边界以 [ADR-0012](../adr/0012-output-drafts-and-format-sequence.md) 为准。

本轮只交付风险清单 Excel。Word、PDF、资料清单、访谈提纲和管理层材料仍属于后续切片，不在本轮宣称完成。

## 数据与审计控制

- 项目数据库迁移新增 `output_drafts`、`output_draft_versions` 和 `output_exports`。
- 草稿仅允许编辑成果标题、风险标题、正文、顺序和编制备注；风险集合、证据、规则输入与计算、风险版本和模型来源继续由源快照锁定。
- 每次保存增加草稿版本并保留完整版本状态；最终固化也形成独立版本。已固化草稿的更新请求由服务端拒绝。
- 未最终固化的草稿不能导出。每次 Excel 生成均创建新文件和新记录，不覆盖历史文件。
- 导出记录保存源快照、草稿版本、模板版本、文件名、大小、SHA-256 和生成时间；下载路径由服务端校验必须位于当前项目的 `exports` 目录。
- 整个生成过程使用本地确定性代码，不调用模型或外部服务。

## Excel 模板与内容

仓库模板为 `templates/risk-register-excel-v1.xlsx`，包含：

1. 风险清单：人工编辑标题与正文、风险状态、规则、模型来源、支持证据与反证编号。
2. 规则与计算：规则编号和版本、输入值、比较基准、计算结果及风险版本。
3. 证据索引：证据编号、方向、来源定位、原文引用、解析方式与源证据 ID。

三个工作表均写入项目、主体、审计期间、快照编号、生成时间、内容摘要、模板版本和数量信息，并使用冻结标题行、筛选表、自动换行和打印宽度设置。

## 浏览器验收

- 深色主题下检查桌面输出页：状态层级、草稿编辑区、锁定证据、固化提示和导出历史可读。

- 未保存修改会禁用最终固化；最终固化后编辑字段和排序按钮均锁定。
- Excel 历史显示文件名、草稿版本、大小和哈希摘要，并提供真实下载入口。

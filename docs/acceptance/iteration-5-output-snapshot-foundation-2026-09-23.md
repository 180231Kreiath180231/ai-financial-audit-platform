# 迭代五输出快照基础验收记录（2026-09-23）

## 范围

本轮实现“已确认风险 → 格式无关不可变快照 → 历史预览”的输出基础。数据边界和后续文件生成约束以 [ADR-0011](../adr/0011-format-neutral-output-snapshots.md) 为准。

本轮不选择固定报告模板，不生成或下载 Word、Excel、PDF 文件，也不实现资料清单和访谈问题。上述范围仍需产品确认格式优先级、模板负责人和业务验收人。

## 已实现

- 项目数据库迁移新增输出快照、快照风险索引和生成时间索引。
- 服务端只读取“已核实”或“已关闭”风险；待复核、待补证和已排除风险不会进入快照。
- 每项风险必须至少有一条支持证据，任一风险证据不完整时整次生成回滚，不留下部分快照。
- 固化项目身份、风险编号与版本、状态、人工意见、确定性规则输入/基线/计算、模型来源、不确定性及支持/反证证据。
- 文档证据保留文档、页码、块号、原文、解析方式与版本；财务证据保留数据集、CSV 行号、期间和科目。
- 规范 JSON 计算 SHA-256；每次生成新建记录和审计事件，不提供覆盖、更新或删除接口。
- 输出页提供准备状态、真实加载/空/成功/错误状态、历史列表和快照详情预览。
- Word、Excel、PDF 显示为明确禁用态，并说明模板和格式优先级尚未确认。

## 自动化结果

统一门禁：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1
```

结果：

- 前端 ESLint：通过。
- 前端 Vitest：25 项通过。
- 前端生产构建：通过。
- 后端 Ruff：通过。
- 后端 Pytest：79 项通过。

浏览器端到端验收：

```powershell
npm.cmd --prefix frontend run e2e
```

结果：9 项适用场景通过，7 项按桌面或移动项目条件有意跳过。输出场景覆盖人工风险创建、合成解释、状态核实、不可变快照生成、证据编号、人工意见和文件格式禁用态。

专项后端测试覆盖：

- 未确认风险不能生成快照。
- 缺少支持证据的已确认风险使整次生成原子失败。
- 已核实风险生成后再转为已关闭，不会修改旧快照。
- 多次生成产生独立 ID、正确倒序历史和独立审计事件。
- 迁移可从既有项目数据库升级到版本 9。

## 浏览器与界面验收

- 在本地合成项目中将确定性规则风险转为“已核实”，成功生成含行级证据引用的快照；刷新页面后历史和引用仍可回看。
- 深色 1440×900、浅色 940×800、手机竖屏 390×844、手机横屏 844×390 均完成真实渲染检查。
- 390 与 844 宽度下页面 `scrollWidth` 等于 `clientWidth`，未出现页面级横向溢出。
- 窄屏输出头、指标、历史与详情按内容优先级堆叠；底部导航和固定状态栏未遮挡主要操作。
- 成功状态使用可访问的 `status`，错误使用 `alert`；装饰图标从辅助技术树隐藏，禁用文件按钮保留原生 `disabled` 语义。

## 验收结论

迭代五输出快照基础通过。当前版本已经具备可追溯、不可覆盖的文件生成前置内容层，但尚不能宣称完成报告导出或完整可用输出闭环。

## 尚未完成

- Word、Excel、PDF 的首发优先级、固定模板、模板负责人和业务验收人未确认。
- 文件渲染、打开性验证、模板字段校验、下载记录和历史文件不覆盖尚未实现。
- 资料清单和访谈问题的内容结构及是否复用风险快照尚未确认。
- 快照保留期限和受控清理策略尚未定义；当前只增不删。

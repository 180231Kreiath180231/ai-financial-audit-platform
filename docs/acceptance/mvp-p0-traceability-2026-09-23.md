# MVP P0 与发布门禁追踪矩阵（2026-09-23，更新于 2026-09-24）

## 判定口径

- **已实现**：生产路径和自动化回归均存在；正式发布前仍可能需要业务或实机验收。
- **部分实现**：已有基础链路，但 PRD 要求、真实兼容或规定规模验收尚未闭合。
- **未实现**：当前生产路径不存在。
- 本矩阵只描述仓库现状，不放宽详细 PRD 的产品范围和发布条件。

## 推荐收口顺序

1. 在 16GB 目标 Windows 轻薄本重复 F01、P01、P02、P03、P04 和 P06，并用获批 synthetic 外部 OCR 账号补做 P05 页级检查点强退；本轮 32GB Windows 实测见迭代十四、十五记录。
2. 通过 Grill Me 确认风险规则、风险分级、访谈新增/删除、输出模板和数据保留策略。
3. 获得外发政策与 synthetic 账号批准后，接入真实文本、视觉和 Embedding 服务并完成兼容测试。
4. 最后完成离线抓包、安装/升级/备份/恢复/卸载演练、许可证归档和审计人员业务验收。

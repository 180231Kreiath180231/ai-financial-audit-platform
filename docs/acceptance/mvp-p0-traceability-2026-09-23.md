# MVP P0 与发布门禁追踪矩阵（2026-09-23）

## 判定口径

- **已实现**：生产路径和自动化回归均存在；正式发布前仍可能需要业务或实机验收。
- **部分实现**：已有基础链路，但 PRD 要求、真实兼容或规定规模验收尚未闭合。
- **未实现**：当前生产路径不存在。
- 本矩阵只描述仓库现状，不放宽详细 PRD 的产品范围和发布条件。

## 推荐收口顺序

1. 先完成不依赖外部政策的本地功能：备忘录、统计分析、F10 增量重算、管理层材料和证据包。
2. 在目标 Windows 设备执行 P01 至 P07 实机性能验收，重点复核 P03/P04 的真实负载采样和前台响应。
3. 通过 Grill Me 确认风险规则、风险分级、访谈新增/删除、输出模板和数据保留策略。
4. 获得外发政策与 synthetic 账号批准后，接入真实文本、视觉和 Embedding 服务并完成兼容测试。
5. 最后完成离线抓包、安装/升级/备份/恢复/卸载演练、许可证归档和审计人员业务验收。

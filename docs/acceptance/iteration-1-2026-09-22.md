## 工程控制

- Registry 与项目数据库均增加 `schema_migrations`，现有建表过程纳入版本 1，重复初始化保持幂等。
- 项目任务增加本地 `audit_events`，记录排队、状态变更、完成和失败事件。
- 应用日志使用 JSON 行格式，只记录项目、任务、状态和错误码等结构化字段，不记录 PDF 正文或密钥。
- GitHub Actions 在 Windows 上复用同一套检查入口，并额外安装 Chromium、运行浏览器验收。
- 损坏文件隔离后更新任务源路径，重试不会退化成错误的 `FILE_MISSING`。
- 本地 E2E 固定使用独立的 5174/8100 端口与 `.runtime/e2e-data`，不复用开发服务或 `data/runtime`。
- 项目目录丢失时保留 Registry 入口并返回可操作错误，不阻断其他项目和应用启动。

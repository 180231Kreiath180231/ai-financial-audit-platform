# 迭代十八项目概览与资料工作区验收记录（2026-09-24）

## 范围与结论

本轮修复 PRD-PROJ-002 的信息架构与交互问题，不改变业务数据、数据库、接口、任务状态机、风险判断或既有输出历史。此前“项目”和“资料”一级区域复用了同一个三栏工作区，用户难以判断两者差异；修复后两者职责明确分离：

- “项目”展示范围、关键指标、建议下一步、审计主流程、最近资料、任务和本地环境状态。
- “资料”负责 PDF 导入、项目检索、文档阅读、证据选择、任务状态和人工处置。
- 当前项目选择器移到全局页头，在六个一级区域中保持一致。
- 移动端“更多”由隐式轮换改为可见菜单，明确提供“输出”和“设置”。

结论：项目概览与资料工作区不再重复，桌面与窄屏主路径均可由自动化和截图复核。

## 实现边界

- 保留项目、资料、分析、风险、输出、设置六个一级区域。
- 保留资料区的左侧队列、中部证据画布、右侧复核与处置，以及窄屏三段切换。
- 项目概览的最近资料和最近任务会直接打开对应文档或任务，不只跳转到泛化入口。
- 页脚上下文按当前一级区域更新，不在分析、输出或设置中继续显示旧文档名称。
- 将用户界面中的迭代编号和部分开发术语改为业务语言；底层模拟服务标识、审计记录与测试契约保持不变。
- 未接入真实 OCR、文本模型、Embedding 或其他外部 API。

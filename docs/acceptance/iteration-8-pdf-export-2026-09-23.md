# 迭代八 PDF 归档导出验收记录（2026-09-23）

## 范围

本轮交付 PDF v1：从同一最终固化草稿直接生成包含风险清单、锁定证据索引、资料清单和访谈提纲的 `.pdf` 归档件。内容和门禁以 [ADR-0016](../adr/0016-pdf-archive-export.md) 为准。

本轮不新增管理层材料、证据包独立成果、统计异常规则或真实模型调用。

## 实现结果

- 项目数据库迁移 v14 允许 PDF 导出，并保留既有 Excel、Word 导出记录和草稿版本复合外键。
- PDF 只能从最终固化且包含三类成果的草稿生成；历史旧草稿不会被静默补写。
- A4 归档件包含封面元数据、风险及证据、资料项目、访谈问题、草稿版本和连续页码。
- 中文字体从 Windows 系统读取并以字体子集嵌入；没有可用字体时生成失败，不输出缺字归档件。
- 每次生成新的文件与导出记录，保存格式、模板版本、草稿版本、源快照、SHA-256、大小和时间。
- 前端解除 PDF 禁用占位，提供真实生成、成功、失败、历史列表和下载状态。

## 自动化与视觉验证

- 后端专项覆盖未固化拒绝、旧草稿拒绝、连续两次导出不覆盖、文件复开、元数据、字体嵌入、关键中文字段、审计事件和 v14 数据迁移。
- 前端专项覆盖最终固化后的 PDF 生成、历史展示和下载链接。
- 完整质量门禁通过：前端 lint、28 项组件测试、生产构建、后端 Ruff 和 93 项后端测试全部通过。
- 完整 Playwright 验收为 9 项通过、7 项按桌面/移动条件跳过；异步反馈调整后再次运行输出主链路，1 项通过。
- 使用包含两个风险、三条证据、两项资料和三条访谈问题的合成样本生成 4 页 PDF。
- pypdf 复开与文本抽取通过；PDFium 逐页渲染检查确认中文无缺字，标题、表格、长文本、页脚和分页无越界、遮挡或重叠。
- 当前 Codex 运行时附带的 Poppler 对仓库既有 PDF 与本轮样本均出现同一解析异常，因此本轮视觉验收使用项目已锁定的 PDFium 渲染路径；该现象不归因于新生成文件。

## 结论与后续

PDF v1 已与 Excel、Word 共享同一最终固化草稿和不可覆盖导出历史，三格式基础链路完成。正式 MVP 仍需按 [P0 追踪矩阵](mvp-p0-traceability-2026-09-23.md) 补齐业务功能、真实服务兼容、资源治理和发布演练。

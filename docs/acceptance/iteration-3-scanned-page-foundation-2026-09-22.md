# 迭代三扫描页视觉基础增量验收（2026-09-22）

## 范围

本增量建立扫描页检测、逐页本地渲染、Fake Vision 固定输出、模型调用审计和页级证据定位。所有测试页面均为 synthetic PDF，未上传真实图像，也未发起外部模型请求。

安全与实现边界见 [ADR-0005](../adr/0005-scanned-page-fake-vision-boundary.md)。

## 已实现

- PDF 页原生文本不足时自动识别为扫描页候选。
- 合成项目按页渲染临时 PNG，记录图像 SHA-256 后调用本地 Fake Vision。
- 临时位图和 PNG 在每页处理后立即释放、删除，不保存页面派生图像。
- `vision-page.v1` 固定 JSON 保存页码、合成文本、置信度、服务商、实际模型和调用编号。
- Fake Vision 调用写入模型审计，关联项目、任务、页面摘要和 `vision` 能力；外部请求固定为 0。
- 真实项目的扫描页只标记为“等待视觉策略”，不渲染、不调用模型、不上传页面。
- 页级状态显示在文档队列和 PDF 阅读器；合成结果可全文搜索并定位至准确页码。
- 项目数据库迁移至版本 4；历史文档保持兼容。

## 自动化结果

统一后端测试共 44 项通过。新增专项覆盖：

- 合成扫描页渲染、Fake Vision 固定结果、任务级模型调用审计和临时目录清理。
- 非合成项目保持 `requires_vision` 且模型调用数为 0。
- 暂停/取消安全点不提交半成品文档，Windows 文件句柄在清理前释放。
- 项目 Schema 版本 4 的升级与幂等初始化。

前端 Vitest 12 项通过，生产构建和 ESLint 通过。

浏览器端到端验收 8 项适用场景通过，6 项按目标设备条件有意跳过。新增场景覆盖空文本层 PDF 上传、扫描页状态、Fake Provider/实际模型展示、外部请求 0 次、合成视觉文本搜索和准确页码定位。

## 验收结论

扫描页视觉基础增量通过。当前版本可以安全、诚实地演示完整的页级视觉任务链路，同时保证真实项目在外发政策未确认前不会上传页面。

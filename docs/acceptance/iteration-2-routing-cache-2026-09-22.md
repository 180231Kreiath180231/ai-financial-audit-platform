# 迭代二网关闭环增量验收（2026-09-22）

## 范围

本轮在既有安全网关上补齐备用模型切换、本地模型缓存和配置安全删除。所有模型响应均来自注入式 synthetic 传输，没有使用真实密钥或发起真实外部网络请求。

关联需求：PRD-MDL-002、PRD-MDL-003、PRD-MDL-005、F04、F05、F12。

## 已实现

- Registry Schema 版本 3：新增本地 `cache_entries`，调用记录增加主备角色和切换来源。
- 主模型在自身重试耗尽后，仅对超时、429 和服务不可用切换下一个满足能力的模型。
- 认证失败、余额不足、请求拒绝和响应格式错误不自动切换，避免掩盖配置或数据问题。
- 缓存指纹覆盖项目、能力、服务商配置、密钥引用、实际模型、提示 SHA-256 摘要和证据 SHA-256 摘要；缓存不保存提示词原文。
- 缓存支持全局启停、条目统计和二次确认清空；命中调用明确记录 `cache_hit` 且本次费用为零。
- 模型档案和服务商支持二次确认删除；服务商存在关联模型时拒绝删除，模型删除同步清理关联缓存。
- 服务商删除成功后移除对应 DPAPI 密文；历史调用记录和删除审计事件保留。
- 设置页显示备用模型标记、备用开关、缓存状态和删除影响范围；原生对话框提供键盘焦点约束和取消路径。

# 迭代十三管理层材料与证据包验收记录（2026-09-24）

## 范围

本轮补齐固定输出模板中的管理层沟通材料和独立证据包，并把四类草稿内容纳入同一编辑、版本和最终固化流程。业务边界以 [ADR-0021](../adr/0021-management-materials-and-evidence-package.md) 为准。

本轮不自动生成管理层结论、责任人或期限，不复制原始证据文件，也不修改已存在的草稿、快照或历史导出。

## 实现结果

- 项目数据库迁移到 v17，草稿保存管理层标题和确定性生成的沟通事项。
- 输出工作区新增“管理层材料”页签，支持编辑标题、事项摘要、回复要求和排序；风险与证据关联保持锁定。
- 四个页签支持方向键、Home 与 End 键盘导航，窄屏保持可用。
- Word/PDF v2 按“管理层材料、风险清单、资料清单、访谈提纲”顺序生成完整成果。
- 新增独立证据包 Excel v1，包含“证据包说明”“风险索引”“证据索引”三张工作表。
- 三张表均写入真实项目、期间、快照、生成时间、内容摘要和数量；证据索引保留来源定位与解析元数据。
- 导出历史新增风险清单、工作成果和证据包类型标识；所有文件继续只增不覆盖。
- 旧草稿迁移后保持空管理层列表；Word/PDF 明确阻止不完整旧草稿，证据包仍可按其固化快照独立生成。

- 109 项后端测试通过，覆盖 v17 迁移、四类草稿门禁、Word/PDF v2、证据包元数据、证据索引和历史不覆盖。
- 前端 lint、37 项组件测试和生产构建通过。

- PDF 直接用 Poppler 渲染 5 页并逐页检查；管理层材料、风险、资料和访谈页面均无溢出、缺字或遮挡。

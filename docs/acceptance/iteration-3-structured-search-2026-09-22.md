# 迭代三结构化检索与文档标注验收（2026-09-22）

## 范围

本轮补齐 PRD-RET-001 的年度、主体、科目、文档类型过滤，并增加文档与解析方式筛选、人工标注和不可覆盖版本历史。所有操作保持本地执行。

## 已实现

- 项目迁移 v7 增加可空文档元数据、索引和 `document_metadata_versions` 历史表，不猜测或回填旧文档字段。
- 文档元数据 API 校验项目年度边界、文本长度、科目数量并记录递增快照版本和项目审计事件。
- 项目检索可组合关键词、文档、年度、主体、科目、文档类型和文档级解析方式，也支持无关键词的筛选浏览。
- 搜索响应携带结构化元数据；前端显示筛选数量、清除入口、标注版本、空结果建议和本地执行状态。
- 提交筛选后自动收起筛选面板，让结果在有限高度的资料队列中立即可见。
- 没有可提取原文的元数据命中仍可打开 PDF，但不会显示支持证据或反证操作。

## 验证

- 后端 Ruff 与 Pytest：通过，62 项测试。
- 前端 ESLint、Vitest：通过，17 项测试；生产构建通过。
- Playwright：9 项通过，7 项按设备条件跳过；覆盖导入、标注版本、无关键词筛选和 PDF 打开。
- 手动浏览器检查覆盖人工标注保存、版本提示、五项组合筛选、空白 PDF 命中保护和结果页打开。

# ADR-0002：模型网关安全边界

- 状态：已接受
- 日期：2026-09-22
- 关联：PRD-MDL-001 至 005、PRD-OFF-001、F04、F05、F12

## 决策

- 服务商入口采用 OpenAI-compatible 配置边界，允许保存显示名称、HTTPS Base URL、超时、重试和默认请求头；认证信息不得放入默认请求头。
- API Key 使用 Windows 当前用户范围 DPAPI 加密，SQLite 只保存不可直接使用的 `dpapi:` 引用。接口与界面不返回完整密钥。
- 真实外发必须同时满足全局严格离线关闭、当前项目显式授权、模型能力匹配和统一网关审计；任一条件不满足即拒绝。
- 业务通过文本、视觉、JSON Schema、工具、Embedding 和文件上传能力声明选择模型，不硬编码厂商模型名。
- 自动化测试与当前阶段的界面自检只使用 Fake Provider。请求摘要使用 SHA-256，不在调用记录中保存提示词原文。
- 本阶段允许配置外部服务商与模型档案，但不执行真实网络请求。真实适配器需在使用 synthetic 数据和测试密钥完成专项验收后另行启用。

## 结果

该边界允许后续接入 OpenAI、DeepSeek 或其他兼容服务，而不改变业务调用入口。默认安装保持严格离线；保存配置或密钥不会自行触发任何外发。

F04 和 F05 的路由结构已经建立，但“两家真实文本模型和一家真实视觉模型”的阶段出口尚未完成。F12 已覆盖外发拦截器的本地测试，仍需在真实适配器接入后补充网络层阻断验证。

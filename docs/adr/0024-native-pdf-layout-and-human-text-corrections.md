# ADR-0024：原生 PDF 版面契约与人工文本校正

- 状态：已接受
- 日期：2026-09-25
- 关联：PRD-DOC-002、PRD-DOC-004、PRD-RET-001、PRD-RET-002、F06

## 背景

既有 PDF 链路保存页码、页级文本和解析方式，但原生 PDF 没有稳定保存页面尺寸、文本区域坐标和表格候选；OCR 或解析文本也缺少可追溯的人工校正入口。接入外部 OCR 并不是解决这些本地数据契约问题的前提，因此本轮先闭合不需要 API Key 的部分。

人工校正不能覆盖来源文本或历史，也不能让全文索引、语义索引和页面显示出现三个不同版本。表格候选只能作为版面线索，不能被系统自动解释为已确认表格或审计结论。

## 决策

1. 项目数据库迁移到 v19。页面文本块保存不可变 `source_text`、当前有效文本、页宽页高、区域坐标、块类型、表格候选元数据、文本版本和最近校正时间。
2. 原生 PDF 使用项目已有的 `pypdfium2` 提取文本矩形，并转换为左上角原点的归一化区域坐标，不新增生产依赖。旧页面和无法取得矩形的页面继续提供准确页码，不伪造坐标。
3. 表格候选只在文本列或多数字行具有明确版面线索时保守标记，元数据始终包含 `confirmed: false`。候选不会自动生成字段、金额、风险或结论。
4. 扫描页继续只承诺页级定位。Fake Vision 或暂时无法提供字符/区域坐标的 OCR 结果保存为单个页级文本块，不宣称字符级精度。
5. 人工校正采用追加式版本记录。每次保存均保留修改前后文本、原因、块序号、版本、人工来源和时间；`source_text` 永不改写，当前有效文本供阅读器、全文检索和证据分块使用。
6. 保存校正后同步重建该页 FTS/检索分块，并将既有向量索引标记为待重建。不会使用过期向量继续声称语义索引就绪。
7. 审计事件只记录文档、页码、块、版本和修改前后 SHA-256，不把可能敏感的完整文本复制到全局审计日志。
8. 本轮只实现文本块校正。结构化金额、风险类型和表格单元格的校正语义会改变财务与风险口径，须经业务决策后另行设计。

## 影响

- PRD-DOC-002 的原生文本、页面尺寸、区域坐标和保守表格候选已有生产契约。
- PRD-DOC-004 从“未实现”推进为“部分实现”：OCR/解析文本可人工校正并保留历史；结构化字段、金额、风险类型和表格单元格仍未实现。
- 既有文档迁移后以原文本回填不可变来源，不重跑解析、不改写风险、证据、输出或导出历史。
- 外部 OCR、视觉模型和 Embedding 仍由统一网关、外发授权与 API Key 控制，本决策不放宽任何外发边界。

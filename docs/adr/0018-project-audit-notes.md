# ADR-0018：项目级审计备忘录与模型读取许可

- 状态：已接受
- 日期：2026-09-23
- 关联：PRD-NOTE-001

## 背景

审计人员需要在风险正式流转和输出固化之外记录复核思路，并把记录定位到一个或多个风险与原始文档页。此类人工工作底稿可能包含尚未形成风险结论的信息，不能因为存在于项目数据库中就自动成为模型上下文。

## 决策

1. 备忘录存储在项目隔离数据库中，包含标题、正文、标签、模型可读开关及创建/更新时间；一个项目可保存多条，按最近更新时间排序。
2. 风险和文档页关联采用独立关系表。写入前必须在同一项目数据库内解析到有效风险和已解析页面，任一关联无效时整笔事务回滚。
3. `model_readable` 默认关闭。开启只表示该备忘录具备被模型任务选择的资格，不绕过严格离线、项目外发授权、服务商能力路由或最小上下文策略。本轮不新增读取备忘录的真实模型任务。
4. 创建、更新和删除均写入项目审计事件。审计事件记录对象编号、模型读取许可和关联数量；删除事件保留标题，但不复制正文，避免在删除后留下第二份内容。
5. 删除必须由用户在原生确认对话框中二次确认；删除备忘录只级联删除关联关系，不删除风险、文档或页面。
6. 备忘录作为风险工作区的二级页面，不增加第七个主导航入口；关联风险和页码可返回现有风险详情或证据阅读器。

## 影响

- 项目迁移 v16 新增 `notes`、`note_risks` 和 `note_pages`。
- 页面关联以创建或更新时已经解析的页面为准；文档删除会级联清除对应备忘录页关联。
- 后续模型功能必须显式过滤 `model_readable = 1`，并继续经过既有网关安全门禁，不能把此字段解释为外发同意。

# ADR-0007：项目级中文全文检索与证据提升

- 状态：已接受
- 日期：2026-09-22
- 关联：PRD-RET-001、PRD-RET-003、PRD-RET-004、F06、F07

## 背景

项目库已创建 FTS5 表，但原接口仍使用 `instr` 逐行扫描且只能搜索当前文档，未形成“跨文档召回—页码定位—证据固化”的本地闭环。默认 FTS5 分词器也不适合中文连续子串检索。

## 决策

- 项目迁移 v6 将 `pages_fts` 重建为 FTS5 trigram 外部内容索引；索引是可重建派生数据，不改变 `pages` 原文。
- 三个及以上字符使用参数化 FTS5 短语查询；一至两个字符使用精确本地子串回退，以支持短科目、年份尾数和金额片段。
- 项目级接口支持文档与页码过滤，单次最多返回 50 条；首版界面固定取前 20 条，避免无界结果占用内存和界面空间。
- 文件名命中在本地元数据中补充召回。每条结果都包含文档、页码、块号、解析方式和解析版本。
- 展示片段必须是服务端原文的精确子串，不能插入高亮标记或省略符号。用户将结果提升为支持证据或反证时，继续由风险服务重新读取原文并校验。
- 检索完全在本地执行，不调用 Embedding、Rerank、OCR 或其他外部服务；界面明确展示“未调用外部服务”。

## 边界

本决策完成 PRD-RET-001 的首个项目级本地闭环，不代表 PRD-RET-002 向量检索或 PRD-RET-003 混合排序已完成。年度、主体、科目和文档类型的结构化过滤仍待后续元数据提取与索引设计。

# ADR-0014：Word 审计工作成果包导出

- 状态：已接受
- 日期：2026-09-23
- 关联：PRD P0 主链路第 8、9 项，F11，ADR-0012，ADR-0013

## 背景

风险清单、资料清单和访谈提纲已经进入同一个可编辑、可版本化且可最终固化的成果包。按照已确认的 Excel、Word、PDF 实施顺序，下一步需要提供可独立使用的 Word 文件，并保证其内容与已固化草稿一致、历史文件不被覆盖。

## 决策

1. 使用仓库版本化模板 `templates/audit-work-products-word-v1.docx` 和 `python-docx` 在本地生成 Word 文件，不调用外部模型或服务。
2. Word v1 是完整审计工作成果包，依次包含项目及固化元数据、风险清单与锁定证据索引、资料清单、访谈提纲。
3. Word 只能从最终固化草稿生成。迁移前创建且缺少资料清单或访谈提纲的历史草稿不得静默补写；用户需从原始快照新建完整草稿。
4. 每次生成使用新的导出编号和文件路径，文件名包含日期、草稿版本和导出编号片段；任何历史导出都不覆盖。
5. `output_exports` 迁移 v12 将允许格式从仅 `xlsx` 扩展为 `xlsx` 或 `docx`，保留既有 Excel 记录和复合外键约束。
6. 导出记录保存格式、模板版本、草稿版本、源快照、文件 SHA-256、大小和生成时间；下载接口按实际格式返回 MIME 类型。
7. 页面尺寸使用 Letter 纵向，正文和表格采用适合中文审阅的保守排版；模板与生成结果均需通过打开、字段、引用、分页和逐页渲染检查。

## 影响

- 优点：用户可从同一最终固化版本获得可编辑 Word 成果包，三类成果及证据引用保持一致并可追溯。
- 代价：新增 `python-docx` 及其 `lxml` 传递依赖，发布包体积与文档渲染专项验证范围增加。
- 不采用：从当前页面 HTML 直接打印为 Word。该方案难以稳定保留标题层级、表格表头、证据索引和模板版本。
- 后续：PDF 仍是下一独立切片，必须继续读取同一最终固化草稿，而不能从 Word 反向提取业务内容。

# ADR-0023：项目助手的上下文、历史与写入边界

- 状态：已接受
- 日期：2026-09-24
- 关联：PRD-RET-004、PRD-RISK-003、PRD-NOTE-001、PRD-MDL-005

## 背景

工作台已有证据选择、项目检索、风险与备忘录能力，但缺少可持续使用的项目级 AI 对话入口。助手既要能回答当前项目问题，也要允许用户询问会计、审计及其他通用知识；同时必须防止通用知识被误认为项目事实、历史消息被静默复用、模型输出直接改变人工结论。

## 决策

1. 桌面端使用底部停靠入口，展开为右侧助手面板；窄屏展开为全屏工作区。入口在项目各一级区域持续可见，但未选择项目时禁用。
2. 回答范围提供“智能组合、已选证据、当前文档、当前项目、通用知识”五档。“智能组合”默认优先项目证据并允许明确标记的通用知识；“通用知识”不读取项目资料。
3. 当前版本不提供互联网检索。界面、调用审计和回答来源均显式记录 `internet_access=false`；不得声称查阅了最新法规、网站或外部资料。
4. 对话及消息保存在当前项目独立 SQLite 中，可逐条删除或删除整段对话。历史消息默认不进入下一次请求，只有用户勾选“本次包含最近对话”时才带入最近六条。
5. 所有项目来源在服务端重新解析和校验。人工选择的证据必须仍能对应同一文档、页码、文本块和原文片段；客户端不能自行声明可信引用。
6. 助手保持只读，不自动修改风险、备忘录或已固化输出。用户可对单条回答显式确认“添加到备忘录”或“创建风险草稿”；前者默认 `model_readable=false`，后者只允许使用带文档页码和文本块的项目引用，并保持“待复核”。
7. 模型请求继续经过统一网关并记录提示词版本、提示词哈希、实际服务商、模型、数据范围、引用和外发状态。项目数据库只保存对话文本及可追溯引用，不保存隐藏思维过程。
8. 当前真实文本模型尚未启用，生产路径使用明确标记的本地 Fake Provider 响应。系统提示词采用 `assistant-system.v1`，全文保存在 `docs/prompts/assistant-system-v1.md`，后续修改必须升级版本并保留既有调用记录。

## 影响

- 用户可在同一入口完成项目取证提问与范围外专业问答，同时清楚区分项目证据、通用知识和本地模拟。
- 对话历史是项目数据的一部分，会随项目备份与恢复；删除操作留存审计事件，但不保留被删除消息正文。
- 真实模型接入仍受严格离线、项目授权、服务商能力和外发审计门禁约束；本 ADR 不代表已启用联网搜索或真实模型业务调用。

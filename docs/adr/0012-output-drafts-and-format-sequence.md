# ADR-0012：输出草稿、固化门禁与文件格式顺序

- 状态：已接受
- 日期：2026-09-23
- 关联：PRD P0 主链路第 8、9 项，F11 报告导出验收

## 背景

ADR-0011 已建立不可变、格式无关的风险清单快照。文件模板、可编辑范围、导出顺序和跨格式一致性此前未确定，不能直接实现真实导出。用户已完成 Grill Me 决策并接受推荐方案。

## 决策

1. 导出顺序为 Excel 风险清单、Word 工作成果、PDF 归档件；三种文件均须可独立使用。
2. 仓库维护通用中文模板 v1，由用户作为首版模板业务验收人；模板文件按版本保存，不在运行时静默替换。
3. 内容范围分阶段交付：先完成风险清单与证据索引，再完成资料清单、访谈提纲和管理层材料；五类成果均保留在 MVP 范围内。
4. 不可变快照与文件导出之间增加独立草稿层。草稿允许编辑成果标题、风险标题、风险正文、风险顺序和编制备注；证据、规则计算、风险版本和模型来源继续来自不可变快照，不允许在草稿中改写。
5. 每次草稿保存生成新版本并保留历史。草稿必须经过显式“最终固化”后才能导出；最终固化版本不可继续编辑，需要调整时从源快照新建草稿。
6. 资料清单和访谈提纲采用本地确定性生成的可编辑草稿；正式业务路径不依赖真实模型，合成演示可使用 Fake Provider。
7. Word、Excel、PDF 最终应由同一已固化草稿生成，要求语义内容一致，不要求像素级版式一致。
8. 每次导出创建新文件和新记录，保存格式、模板版本、草稿版本、源快照、文件 SHA-256、大小和时间；历史导出不得覆盖。

## 首个实现切片

- 新增 `output_drafts`、`output_draft_versions` 和 `output_exports`。
- 使用 `templates/risk-register-excel-v1.xlsx` 生成 Excel 风险清单、规则与计算、证据索引三个工作表。
- Excel 仅从最终固化草稿生成；生成过程完全本地，不调用模型或外部服务。
- Word 和 PDF 在后续切片接入，但必须复用本 ADR 定义的草稿与固化门禁。

## 影响

- 优点：把人工编辑与来源事实分离，既能满足成果编制需要，又不会破坏证据链；格式扩展时可复用同一内容版本。
- 代价：增加草稿状态、版本表和导出记录，前端需要明确显示未保存、编辑中、已固化和导出失败状态。
- 不采用：直接从当前风险表生成文件。该方案会让历史内容随风险变化而漂移，也无法记录人工编制版本。

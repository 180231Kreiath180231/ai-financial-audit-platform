# ADR-0021：管理层材料与独立证据包

- 状态：已接受
- 日期：2026-09-24
- 关联：PRD-EXP-001、PRD-EXP-003、F09、F11

## 背景

既有输出链路已能从不可变风险快照生成风险清单、资料清单和访谈提纲，并从最终固化草稿导出 Excel、Word 与 PDF。详细 PRD 还要求管理层沟通材料和独立证据包。两类成果必须复用同一证据边界，不能在导出时静默产生新的审计结论，也不能把索引文件误称为原始证据归档。

## 决策

1. 每项已确认风险确定性生成一条管理层沟通事项。风险编号、风险关联、风险数量和证据编号保持锁定；事项标题、摘要、回复要求和顺序允许人工编辑。
2. 默认文案只复述风险快照中的既有摘要、人工意见或模型解释，并要求管理层确认事实和说明后续安排。系统不自动填写管理层结论、责任人或完成期限。
3. 管理层材料与风险清单、资料清单、访谈提纲共享一个草稿版本和最终固化动作。Word/PDF v2 必须同时包含四类内容，旧草稿保持不变且不会被后台补写。
4. 独立证据包采用 `evidence-package-excel-v1`。它从同一最终草稿与不可变快照生成说明、风险索引和证据索引，保存来源类型、来源定位、原文引用、解析信息、源证据 ID、文档/数据集 ID、页码、行号、期间与科目编码。
5. 证据包只建立可复核索引，不复制原始 PDF、CSV 或其他证据文件；文件内显式说明这一边界，原始文件仍按项目数据保管策略保存。
6. 所有导出继续只增不覆盖，记录模板版本、草稿版本、源快照、SHA-256 和文件大小。API 的 `artifact_kind` 由既有格式与模板版本确定，无需改写历史导出记录。
7. 项目数据库迁移到 v17，仅为输出草稿增加管理层标题与 JSON 内容。既有草稿迁移后管理层列表为空，用户可从原快照新建完整草稿。

## 影响

- 固定模板范围现已覆盖风险、资料、访谈、管理层材料和独立证据包。
- Word/PDF 模板升级到 v2；旧导出文件及其哈希保持不变。
- 证据包不是原始证据集合，也不替代证据文件的备份、保留或访问控制。
- 下一阶段可转入目标 Windows 设备的 P01 至 P07 实机性能验收和正式业务签收。

# ADR-0011：格式无关的不可变输出快照

- 状态：已接受
- 日期：2026-09-23
- 关联：P0 主链路第 8、9 项，F09，证据链与报告导出专项门禁

## 背景

风险台账已经能够保存证据、规则版本、人工复核和不可覆盖的风险版本。正式 Word、Excel、PDF 模板及三种格式的优先级仍属于待产品确认事项，因此当前不能擅自选择模板或把某一格式声明为正式交付物。

同时，后续任何文件生成都需要一个稳定、可验证且不随后续风险变化而漂移的内容来源。直接从实时风险表生成文件会使历史成果难以复核，也无法证明同一次导出的字段、状态和证据引用一致。

## 决策

- 新增格式无关的 `risk_register` 输出快照，作为后续 Word、Excel、PDF 生成的唯一内容基线。
- 只纳入状态为“已核实”或“已关闭”的风险；“待复核”“待补证”和“已排除”风险不得进入快照。
- 每项风险必须至少保留一条支持证据，否则整个快照原子失败，不产生部分成果。
- 快照固化项目身份、风险编号与版本、状态、人工意见、规则输入/基线/计算结果、模型来源、不确定性和完整证据索引。
- 证据引用使用稳定的 `风险编号-E序号` 形式，同时保留源证据 ID、文档页块或 CSV 行号、原文、解析方式与版本。
- 快照内容使用排序后的规范 JSON 计算 SHA-256；摘要不包含生成时间，因此只反映业务内容。
- 每次生成都创建新记录和审计事件。系统不提供更新或删除接口，后续风险流转不会覆盖既有快照。
- 前端可以预览快照和历史记录，但 Word、Excel、PDF 按钮保持禁用，并明确提示模板与格式优先级尚未确认。
- 后续文件生成必须引用 `snapshot_id`，不得重新读取实时风险表后静默替换快照内容。

## 后果

- 当前版本形成“人工确认风险 → 不可变内容快照 → 历史预览”的安全闭环，但尚未形成可下载文件。
- 文件模板决策完成后，可以在不改变风险和证据模型的情况下增加格式渲染器、文件完整性校验与下载历史。
- 相同内容允许生成多个快照；它们可能具有相同内容摘要，但拥有不同 ID、生成时间和审计事件。
- 当前没有快照删除能力。若未来需要清理或保留期限，必须另行定义可恢复策略并完成产品确认。

## 未决事项

- 首批固定报告模板、模板负责人和业务验收人。
- Word、Excel、PDF 的实现优先级，以及三种格式是否都属于首个可用版本的发布门禁。
- 资料清单和访谈问题是否与风险清单共用同一快照，或使用独立的输出类型与版本。

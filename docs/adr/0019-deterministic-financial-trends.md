# ADR-0019：确定性财务趋势与稳健统计口径

- 状态：已接受
- 日期：2026-09-23
- 关联：PRD-RISK-002

## 背景

科目余额表已有不可变数据集、确定性勾稽规则和行级证据，但尚不能解释多年变化、稳健偏离或结构占比。样本通常只有 11 年，普通 Z-score 对单个极端值敏感，也不能替代会计口径和人工判断。

## 决策

1. `FIN-TREND-v1` 以每个科目的期末净额（期末借方减期末贷方）作为统一序列，金额单位沿用数据集的“元”和币种，不隐式转换方向或单位。
2. 同比比较同一期间的上年值；连续上升或下降只跨相邻期间计算，遇到缺失期间立即重置。系统列出数据集范围内该科目缺失的所有期间，不用零填充。
3. 趋势拐点要求连续三个有效期间，且相邻增减方向从上升变下降或从下降变上升。
4. 同时提供中位数、MAD、均值、总体标准差、标准 Z-score，以及 `0.6745 × (值-中位数) / MAD` 的稳健 Z 值。MAD 为零或样本少于三期时不输出对应 Z 值。
5. 样本少于三期标记为“样本不足”；三至十一期标记为“小样本”。即使超过十一期，统计信号仍需人工复核。标准 Z-score 只产生文字辅助信号，不自动生成风险、不改变风险等级。
6. 结构占比不根据科目编号或名称猜测会计分类。用户必须显式选择资产、收入或费用总计科目作为分母；分子和分母均取期末净额绝对值，分母为零或当期缺失时不计算。
7. 结果由不可变数据集按需重算，不另存派生金额。API、界面与验收记录都显示分析版本、数值口径、分母、缺失期间和不确定性。

## 影响

- 新增数据集科目列表与趋势分析只读 API，不新增数据库迁移。
- 图表只提供趋势概览；精确值、信号和结构占比始终同时出现在可访问数据表中。
- 若后续把统计信号转为风险草稿，必须定义独立、版本化规则，并继续固定为“待评估”，不能直接复用 Z-score 作为高风险判定。

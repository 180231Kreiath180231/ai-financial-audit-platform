# ADR-0013：资料清单与访谈提纲的确定性草稿

- 状态：已接受
- 日期：2026-09-23
- 关联：PRD P0 主链路第 8、9 项，ADR-0012

## 背景

ADR-0012 已决定资料清单和访谈提纲采用本地确定性生成的可编辑草稿，并与风险清单共用最终固化版本。实现仍需明确项目粒度、可编辑范围和旧草稿兼容方式，避免三类成果形成互相失配的独立版本。

## 决策

1. 一个输出草稿同时包含风险清单、资料清单和访谈提纲，共用成果包标题、编制备注、版本号、编辑状态和最终固化动作。
2. 每项快照风险确定性生成一条资料索取项，包含稳定项目编号、关联风险、资料名称、取证用途、索取范围和优先级。
3. 每项快照风险确定性生成两条访谈问题：事实背景问题与证据/复核控制问题。问题包含稳定编号、关联风险、建议访谈对象、问题正文和访谈目的。
4. 用户可以编辑三类成果的显示标题、正文、优先级和顺序；资料项、访谈项的编号、数量、风险关联和风险编号由服务端锁定，不允许浏览器新增、删除、重复或改绑。
5. 自动生成内容是审计准备草稿，不生成新的风险分级、金额计算、责任判断或审计结论；生成过程不调用外部模型。
6. 草稿保存时，三类成果作为同一不可变版本状态写入 `output_draft_versions`；最终固化后全部不可编辑。
7. 数据库迁移只追加新列。迁移前草稿保留原内容且新分区为空，不静默补写历史版本；需要三类完整内容时从原始快照新建草稿。
8. 当前 Excel v1 仍只输出风险清单、规则计算和证据索引。资料清单与访谈提纲先进入格式无关草稿，后续 Word/PDF 必须读取同一已固化版本。

## 影响

- 优点：三类成果始终来自同一风险快照和人工编辑版本，后续多格式导出不会出现语义漂移。
- 代价：草稿 API 与迁移增加两个分区的数据结构；旧草稿不会被追溯性重写。
- 不采用：为资料和访谈建立独立草稿及独立固化。该方案会允许不同成果引用不同风险版本，削弱审计轨迹的一致性。

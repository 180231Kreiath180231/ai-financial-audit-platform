# ADR-0015：已完成功能评审加固控制

- 状态：已接受
- 日期：2026-09-23
- 关联：PRD-UPL-004、PRD-RISK-001、PRD-RISK-003、PRD-RISK-005、PRD-EXP-003、F03、F09、F11、P07

## 背景

对当前纵向链路复核后，发现人工确认边界、外部 OCR 恢复、Excel 文本写入、规则编号和磁盘不足处理仍存在可触发缺口。自动化主链路虽然通过，但这些缺口可能造成未经复核的模型内容进入输出、恢复后重复外发、工作簿公式注入、规则追溯歧义或遗留未登记暂存文件。

## 决策

1. 模型解释只能写入状态为“待复核”的风险。API 与领域仓双重校验；终态或待补证风险在界面显示非交互说明。
2. 项目数据库迁移 v13 增加外部视觉页检查点。远端成功结果在整份文档提交前立即保存，任务恢复时按任务和页码复用，并记录保存与复用审计事件。
3. Excel 生成器对所有以公式前缀开头的非可信字符串显式设置文本单元格类型；不改变确定性数值字段的数据类型。
4. 单科目余额公式使用 `TB-ACCOUNT-ROLLFORWARD-001`，跨期衔接使用 `TB-PERIOD-CONTINUITY-001`。历史结果不回写，新结果不再共用规则编号。
5. PDF 暂存前及每个写入块前检查项目卷可用空间，保证写入后仍保留至少 10GB；空间不足或写入失败时删除当前未登记暂存文件并返回可操作错误。

## 影响

- 已人工确认风险不会被后续模型内容绕过复核状态。
- 正常任务恢复不再重复提交已成功的外部 OCR 页；服务商不支持幂等键时，远端成功返回与本地检查点写入之间仍存在不可消除的极小进程崩溃窗口，调用审计保留远端 Job ID 供人工核查。
- Excel 中原样显示公式样式文本，不作为公式执行。
- 修复前历史规则结果与导出保持不可覆盖；稳定编号只约束修复后的新运行。
- 不新增任意 PDF 文件大小上限，避免擅自改变产品范围；磁盘安全线是本轮唯一容量门禁。

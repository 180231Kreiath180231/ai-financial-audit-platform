# ADR-0008：人工文档元数据与结构化检索筛选

- 状态：已接受
- 日期：2026-09-22
- 关联：PRD-RET-001、PRD-DOC-003、F06、F07

## 背景

项目级全文检索已经能够从全部 PDF 原文和文件名召回结果，但 PRD-RET-001 还要求按年度、主体、科目和文档类型过滤。当前尚未批准用于这些字段的模型抽取策略，自动从文件名或正文推断会把未经确认的值伪装成事实。

## 决策

- 项目迁移 v7 为文档增加可空的年度、主体、文档类型、科目标签和元数据版本字段；不为既有文档自动回填或猜测值。
- 科目以规范化 JSON 数组保存，筛选使用 SQLite JSON 精确成员匹配；年度、主体和文档类型使用结构化等值筛选。
- 人工保存每次生成递增版本，并把完整快照、变更原因和时间写入 `document_metadata_versions`；项目审计事件只记录文档、版本和字段名，不复制正文或敏感值。
- 文档年度必须位于项目年度范围内。每个字段都有长度、数量或数值边界，空值明确表示“未标注”。
- 结构化筛选可与关键词、文档、页码和文档级解析方式组合，也可在没有关键词时独立浏览匹配文档。
- 仅通过元数据命中且没有可提取原文的 PDF 仍可打开查看，但不能直接提升为空证据。
- 全部元数据编辑与筛选均在本地完成，不调用模型或其他外部服务。

## 边界

本决策不等同于自动元数据抽取，也不声明人工字段已由审计程序核实。向量检索、混合排序和模型生成标签仍需单独的数据外发与模型能力决策。

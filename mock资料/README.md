# Mock 资料说明

本目录只保存软件演示所需的合成资料，不包含真实企业、客户、合同、发票或财务数据。

| 文件 | 演示用途 |
| --- | --- |
| `01_年度审计情况说明_合成.pdf` | 原生文本解析、全文检索、合成混合检索和页级证据 |
| `02_销售合同与回款核对_合成.pdf` | 收入截止性、合同条款、期后回款和反证复核 |
| `03_扫描发票样本_合成.pdf` | 扫描页检测、逐页 Fake Vision 和零外发审计 |
| `04_科目余额表_2024_2025_合成.csv` | CSV 预览、本地确定性规则、行级证据和风险草稿 |

余额表故意设置一处 2025 年应收账款期初与 2024 年期末不衔接，并由权益科目形成对应的年度期初差异，用于展示规则失败与人工复核流程。所有金额单位为人民币元。

# 衡鉴审计工作台生产设计系统

本文件以 `prototypes/v3.2/` 为视觉与交互基准，并结合 UI/UX 检索结果固化生产实现约束。发生冲突时，以根目录 `AGENTS.md` 和 V3.2 基准为准。

## 设计读法

- 产品：单人内部审计工作台，不是营销门户。
- 语言：企业分析产品、Swiss 网格、克制的深色金融数据工作台。
- 设计参数：variance 4、motion 2、density 8、redesign preserve。
- 默认深色，同时完整支持浅色；不使用外链字体、营销 Hero、滚动入场或装饰性光效。

## 信息架构

- 六个一级区域：项目、资料、分析、风险、输出、设置。
- “项目”是项目级控制台，集中展示审计范围、处理与风险指标、建议下一步、主流程、最近资料和本地运行状态；不重复资料工作区。
- “资料”是证据工作区，保留左侧资料与任务队列、中部证据画布、右侧复核与处置。
- 当前项目选择器固定在页头；切换项目不依赖进入“项目”或“资料”区域。
- 右侧保留判断依据、AI 解释、人工处置三步；未实现能力必须显示禁用态，不伪造成功。
- 窄屏的资料区保留资料、证据、处置三段切换；底部固定项目、资料、分析、风险四项，“更多”以明确菜单承载输出和设置。

## 排版与密度

- 使用 Windows 系统字体栈：Segoe UI、Microsoft YaHei UI、Microsoft YaHei、system-ui。
- 正文移动端不低于 16px；桌面高密度辅助文字不低于 10px，且仅用于非关键元数据。
- 4/8px 间距体系；控件桌面最小 38px，移动触控目标至少 44px。
- 金额、哈希、分数和资源指标使用系统等宽字体栈。

## 组件与布局

- 以连续画布、分区线和留白建立层级，避免卡片套卡片。
- 半径只使用 5px 与 8px；主按钮、输入框和面板不得随意混用大圆角。
- 断点重点覆盖 1240、940、620px；额外验证 1440、1180、768、390、375px。
- 图标统一使用 Phosphor outline；有可见文字的装饰图标设置 `aria-hidden`。

## 动效与可访问性

- 仅使用 80–180ms 状态反馈；禁止滚动入场、循环装饰动画和布局位移。
- 完整支持 `prefers-reduced-motion`。
- 键盘焦点使用至少 2px 高对比焦点环；粘性栏不得遮挡焦点。
- 对话框支持 Escape、初始焦点和语义化标题；表单错误保留在字段附近或对话框内。
- 深浅主题正文对比度至少 4.5:1，控件与焦点边界至少 3:1。

## 禁止项

- 不使用 Emoji 作为结构图标。
- 不使用外链字体、渐变发光、玻璃拟态或营销页模板。
- 不把模拟 toast 当作后端成功。
- 不在生产状态层硬编码原型金额、企业和风险结论。
